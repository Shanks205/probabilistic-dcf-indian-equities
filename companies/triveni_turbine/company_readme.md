# Triveni Turbine — Company 3

## Role in the Project

Triveni Turbine is the third company in the probabilistic DCF valuation project. It represents the capital-goods / order-book conversion archetype and adds a different uncertainty profile from Hero MotoCorp and Fiem Industries.

## Valuation Archetype

```text
Capital goods / order-book driven growth
```

## Main Uncertainty Drivers

The Monte Carlo model focuses on:

1. order inflow and order-book conversion,
2. export growth,
3. aftermarket/service mix,
4. industrial capex cycle,
5. operating margin sustainability,
6. working-capital intensity,
7. capex intensity,
8. WACC and terminal growth.
