# Fiem Industries Preliminary Probabilistic DCF Note

## Company Role in the Project

Fiem Industries is Company 2 in the probabilistic DCF valuation project. It represents the auto-component growth archetype. The company adds uncertainty around two-wheeler cycle exposure, customer/platform concentration, LED lighting content, EV transition opportunities, and operating margin sustainability.

## Modelling Objective

The objective is not to issue a target price. The objective is to demonstrate how the same FCFF DCF and Monte Carlo framework can be applied to a midcap auto-component company with different uncertainty drivers from Hero MotoCorp.

## Deterministic DCF Output

The first-pass deterministic DCF model produces the following preliminary outputs:

| Output | Value |
|---|---:|
| PV of explicit FCFF | Rs 641.18 crore |
| PV of terminal value | Rs 1,091.58 crore |
| Enterprise value | Rs 1,732.76 crore |
| Equity value | Rs 2,008.96 crore |
| Fair value per share | Rs 76.33 |

This is not a target price. It is a model architecture output based on preliminary assumptions.

## Monte Carlo Output

The Monte Carlo simulation uses 10,000 simulations and produces the following preliminary valuation range:

| Metric | Value |
|---|---:|
| Mean fair value per share | Rs 74.62 |
| Median fair value per share | Rs 73.75 |
| 5th percentile | Rs 56.30 |
| 25th percentile | Rs 66.15 |
| 75th percentile | Rs 82.10 |
| 95th percentile | Rs 95.90 |

## Interpretation

The current output demonstrates how valuation uncertainty behaves for an auto-component company with higher business-specific risk than a mature large-cap auto company. Fiem's valuation dispersion is driven by revenue growth, margin sustainability, working capital intensity, capex needs, and a higher discount rate.

The key learning for the project is that a midcap growth supplier requires different probability assumptions from a mature original equipment manufacturer. A single generic DCF template would hide those differences.

## Key Uncertainty Drivers

For Fiem Industries, the main uncertainty drivers are:

1. two-wheeler industry cycle,
2. customer and platform concentration,
3. LED content-per-vehicle growth,
4. EV component opportunity,
5. margin sustainability,
6. working capital intensity,
7. capex requirements,
8. WACC and terminal-growth assumptions.
